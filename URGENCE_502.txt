🎯 SOLUTION IMMÉDIATE #1 : ACCÈS DIRECT (CONTOURNER NGINX)
===============================================================================

Oubliez nginx pour l'instant ! Accédez DIRECTEMENT aux services :

┌─────────────────────────────────────────────────────────────┐
│  DOUBLE-CLIQUEZ SUR : acces-direct-services.bat             │
└─────────────────────────────────────────────────────────────┘

OU ouvrez manuellement dans votre navigateur :

   🌐 http://localhost:3000          ← Frontend (Page d'accueil)
   🌐 http://localhost:8000/admin/   ← Django Admin
   🌐 http://localhost:8000/api/docs/ ← API Swagger

IMPORTANT : Utilisez le port 3000 pour le frontend, PAS le port 80 !


🔧 SOLUTION IMMÉDIATE #2 : CORRECTION FORCÉE NGINX
===============================================================================

Si vous voulez absolument utiliser nginx sur le port 80 :

┌─────────────────────────────────────────────────────────────┐
│  DOUBLE-CLIQUEZ SUR : fix-nginx-force.bat                   │
└─────────────────────────────────────────────────────────────┘

Ce script va :
1. Arrêter nginx
2. FORCER la modification du port (80 → 3000) dans nginx.conf
3. Reconstruire nginx SANS cache
4. Redémarrer nginx
5. Vérifier la configuration

🎬 SCÉNARIOS DE DÉPANNAGE
===============================================================================

SCÉNARIO A : Frontend http://localhost:3000 fonctionne
────────────────────────────────────────────────────────

✅ SOLUTION : Utilisez le port 3000 directement !
   Pas besoin de nginx pour le développement.

   Accès :
   - Frontend : http://localhost:3000
   - Backend : http://localhost:8000
   - Admin : http://localhost:8000/admin/


SCÉNARIO B : Frontend http://localhost:3000 ne fonctionne PAS
──────────────────────────────────────────────────────────────

❌ Problème : Le service frontend ne démarre pas

✅ SOLUTION :
   1. docker-compose logs frontend
      → Chercher l'erreur (node_modules manquants ?)

   2. docker-compose restart frontend
      → Redémarrer le service

   3. docker-compose exec frontend npm install
      → Réinstaller les dépendances si nécessaire

   4. docker-compose restart frontend
      → Redémarrer après install


SCÉNARIO C : Je veux ABSOLUMENT utiliser nginx sur port 80
────────────────────────────────────────────────────────────

✅ SOLUTION : Exécutez fix-nginx-force.bat

   Ce script va modifier DIRECTEMENT nginx.conf pour utiliser
   le port 3000 au lieu du port 80.

   Après exécution, testez : http://localhost


SCÉNARIO D : RIEN ne fonctionne
────────────────────────────────

🆘 SOLUTION ULTIME : Reset complet

   docker-compose down -v
   docker-compose build --no-cache
   docker-compose up -d

   Attendre 2-3 minutes, puis tester :
   - http://localhost:3000 (frontend direct)
   - http://localhost:8000/admin/ (backend direct)
