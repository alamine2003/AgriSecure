💡 EXPLICATION TECHNIQUE (Pour le Jury)
-------------------------------------------------------------------------------

Problème : Incompatibilité port frontend mode dev vs prod

En mode développement :
- Frontend utilise Vite (serveur dev) sur port 3000
- Hot Module Replacement (HMR) actif
- Rechargement automatique du code

En mode production :
- Frontend build statique servi par nginx sur port 80
- Fichiers optimisés et minifiés
- Pas de HMR

Solution : Configuration nginx adaptative
- docker-entrypoint.sh détecte NGINX_MODE=dev
- Utilise nginx.dev.conf (port 3000) en dev
- Utilise nginx.conf (port 80) en prod
- Support WebSocket pour HMR Vite
